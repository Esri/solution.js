Custom Params

Paste a JSON object whose properties will be added to the deploy's templateDictionary.params. Templates can reference these via {{params.<key>...}}.

To exercise a buildSolution payload (e.g. from solutions-components), wrap it under a buildSolution key so templates can resolve it as {{params.buildSolution.items.<id>.title}}: 

{
  "buildSolution": {
    "solution": { "item": { "id": "<solutionItemId>", ... }, ... },
    "items": { "<itemId>": { "title": "...", ... } }
  }
}

If the Solution Id field above is empty, it will be pulled from buildSolution.solution.item.id.
